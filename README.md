# Colour Changer

A simple JavaScript project that changes the background color when the user clicks the "Change Color" button.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Change background color
- Display the current color code
- Reset the background color

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Click the **Change Color** button.
